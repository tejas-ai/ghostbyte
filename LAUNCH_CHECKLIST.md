# QuietSend Launch Checklist

## App Store / Distribution
- [ ] **App title with keywords**: Ensure the title includes relevant search terms.
- [ ] **Subtitle**: Brief, catchy summary (don't leave empty).
- [ ] **App description**: Hook the user in the first 2 lines.
- [ ] **Keywords**: Researched and correctly added.
- [ ] **Screenshots**: Show benefits/value, not just features.
- [ ] **App preview video**: Optional but highly recommended.
- [ ] **Privacy policy URL**: Accessible online.
- [ ] **Support URL**: Direct link to support channel.
- [ ] **App category**: Correctly selected.
- [ ] **Age rating**: Completed questionnaire.
- [ ] **Landing page live**: Website is up and running.

## Technical / SEO
- [ ] **Open Graph tags**: *Missing in index.html*
    - [ ] `og:title`
    - [ ] `og:description`
    - [ ] `og:image`
    - [ ] `og:url`
- [x] **Favicon**: Added to `index.html` / public folder. *Verified*
- [x] **Mobile responsive**: *Meta viewport tag exists, styles use Tailwind.*
- [ ] **SSL certificate**: HTTPS is active (dependent on deployment).
- [x] **Download/CTA button**: *Implemented in UI.*
- [ ] **Google Search Console**: Connected for indexing.
- [ ] **Bing Webmaster Tools**: Connected.
- [ ] **Sitemap**: `sitemap.xml` submitted and accessible. *Missing in public/*
- [ ] **IndexNow**: Configured (if applicable).
- [ ] **Meta title and description**: *Title exists, Description missing.*
- [ ] **Robots.txt**: File exists in root. *Missing in public/*

## Marketing
- [ ] **Launch post drafted**: Blog or social media announcement.
- [ ] **Social media assets**: Images, videos, captions ready.
- [ ] **Email list notified**: Newsletter sent.
- [ ] **Product Hunt listing**: Prepped (if launching there).
- [ ] **Community support**: Friends and network ready to engage.

## Legal
- [ ] **Privacy policy**: Written and linked.
- [ ] **Terms of service**: Written and linked.
- [ ] **Data handling**: Documented (internal/external).
- [ ] **GDPR compliance**: Checked (if applicable to EU users).
- [ ] **Cookie notice**: Implemented (if tracking cookies are used).
